# AnimeSR native host

The host runs two fixed FP16 TensorRT pipelines:

`1280x720 RGBA -> AnimeSR x4 -> 5120x2880 AV1/fMP4`

`1920x1080 RGBA -> AnimeSR x4 -> 7680x4320 AV1/fMP4`

`1920x1080 RGBA -> AniScale2 x2 -> 3840x2160 AV1/fMP4`

It does not resize the AnimeSR output. Native Messaging is used only to start
the host and obtain a token-authenticated `127.0.0.1` WebSocket endpoint.

## Local installation

The current Windows beta reuses an existing compatible Python/TensorRT runtime,
PyNvVideoCodec, and locally built engines. It does not import application code
from that runtime. AniScale2 model files are not distributed by this repository;
the installer copies the local engine generated by TheAnimeScripter. AniScale2
comes from [Sirosky/Upscale-Hub](https://github.com/Sirosky/Upscale-Hub/releases/tag/AniScale2)
under CC BY-NC 4.0.

```powershell
powershell -ExecutionPolicy Bypass -File .\native\install.ps1
```

Pass `-ExtensionId`, `-PythonPath`, `-ModelDirectory`, or
`-AniScaleModelDirectory` when your unpacked extension ID or runtime location
differs. Restart Edge and reload `dist-chrome` after installation.

Run the protocol check without loading CUDA:

```powershell
python .\native\animesr_host.py --self-test
```

Run the CUDA/TensorRT/AV1 end-to-end smoke tests after copying both engines into
`native/models` or setting `ANIMESR_MODEL_DIR`:

```powershell
python .\native\smoke_test.py
python .\native\smoke_test.py --width 1920 --height 1080
python .\native\smoke_test.py --mode aniscale2 --width 1920 --height 1080
```
